# 在线查询故障修复

## 已确认原因

当前实现调用 `api.dictionaryapi.dev`。在本机网络中，对该域名的请求在 15 秒内没有收到任何响应，因此浏览器搜索会长时间处于“查询中”，最后显示“暂时无法连接在线词典”。这不是页面数据渲染错误，而是当前第三方服务的网络可达性/响应问题。

## 修复内容

1. 将默认查询来源更换为 `DictionaryAPI.dev` 的可直连 JSON 接口，并在接口模块中封装其返回数据，继续输出当前详情页所需的统一词条结构。
2. 为每次请求增加 `AbortController` 超时（约 5 秒）。超时后立即停止请求，恢复查询按钮，并显示“查询超时”的明确提示，避免长时间等待。
3. 保留可扩展的 provider 层：如主服务不可用，后续可在同一模块添加备用词典 provider；页面不直接依赖特定 API 的原始返回格式。
4. 保持内置词条和导入词库的本地优先逻辑；在线请求失败时不清空用户当前正在阅读的词条。
5. 更新 README，说明默认在线服务和 5 秒超时行为；重新执行生产构建验证。
